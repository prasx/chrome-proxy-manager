Добро пожаловать в Proxy Manager
Расширение решает, какой трафик отправить через прокси, а какой оставить напрямую. Настройка займёт меньше минуты.
Что умеет Proxy Manager
Правила, проверка прокси и автоматическое переключение при сбоях.
Автоматический режим
Недоступные сайты добавляются в прокси, остальное идёт напрямую.
Несколько прокси
Если активный сервер перестал отвечать, трафик уходит на резервный.
Проверка и статистика
Внешний IP, отклик и история маршрутов — в одном месте.
Настройте прокси
Добавьте прокси-сервер. Его можно проверить прямо здесь.
Авторизация (необязательно)
Chrome не поддерживает авторизацию SOCKS4/SOCKS5. Используйте привязку по IP или HTTP(S)-прокси.
Заполните хост и порт прокси
Готово
Proxy Manager настроен. Дальше можно добавить правила и посмотреть статистику в панели управления.
Подсказка
Иконка расширения на панели Chrome открывает быстрый доступ к состоянию прокси.
